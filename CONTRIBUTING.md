# Contributing to Trade Sensei

First off, thanks for taking the time to contribute!

## Contributor License Agreement (CLA)

**Mandatory Legal Requirement:** All external contributors must agree to a Contributor License Agreement (CLA) before any pull request can be merged. By signing the CLA, you assign commercial exploitation rights to the project owner while retaining the right to use your own contributions. 

Please review and sign the CLA at [link-to-cla] before submitting your pull request. Pull requests without a signed CLA will not be merged.

## Reporting Bugs

* Use the GitHub issue search to check whether the bug has already been reported.
* Check if the issue has been fixed by trying to reproduce it using the latest `main` branch in the repository.
* Create an issue, providing as much context as possible.

## Pull Requests

* Fill in the required template.
* Do not include issue numbers in the PR title.
* Include screenshots and animated GIFs in your pull request whenever possible.
* End all files with a newline.
