## MODIFIED Requirements

### Requirement: Check-in Hub
The system SHALL provide a "Check-in Hub" where users can record pre-market bias and post-market reviews.

#### Scenario: Navigating the Check-in Hub
- **WHEN** a user visits the /checkin page
- **THEN** the system SHALL display the current check-in status and history, with help tooltips provided for each section (Bias, Focus, Review) sourced from the centralized help dictionary.
