## MODIFIED Requirements

### Requirement: Workspace sidebar includes Correlation Explorer navigation entry

The Portfolio Workspace sidebar SHALL include a "Correlation Explorer" navigation link pointing to `/dashboard/workspace/correlation`, grouped under the Reporting section alongside the existing Reporting Hub link.

#### Scenario: Correlation Explorer appears in sidebar
- **WHEN** the user views the Workspace sidebar
- **THEN** a "Correlation Explorer" link is visible under the Reporting section
- **AND** clicking it navigates to `/dashboard/workspace/correlation`
